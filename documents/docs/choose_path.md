# Getting started with UFO²

This workspace is set up for UFO² desktop automation on Windows.

1. Follow the [UFO² quick start](getting_started/quick_start_ufo2.md).
2. Configure model credentials in `config/ufo/agents.yaml`.
3. Adjust runtime and MCP options in `config/ufo/system.yaml` and `config/ufo/mcp.yaml`.
4. Run a task with `python -m ufo --task <task-name> -r "<request>"`.

See the [configuration guide](configuration/system/overview.md) and [UFO² overview](ufo2/overview.md) for details.
